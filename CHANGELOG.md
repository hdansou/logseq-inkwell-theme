## [0.1.0] - unreleased

### Added

- Inkwell Slate variant (`themes/inkwell-slate.css`): one file for light and dark, usable as a plugin theme or as `custom.css`.
- Variant layout: shared `src/base.css` + one palette per variant in `src/palettes/`, generated by `npm run build`, which also registers each variant (light + dark) in `package.json`.
- Variable mapping for all three layers Logseq reads (shui HSL channels, `--lx-*` scales, `--ls-*`), declared on `html[data-theme][data-color]` so it holds under every accent colour.
- Styling for DB-graph content (headings, bullets, links, tags, properties, task icons, callouts, background colours) and Base UI surfaces (palette, dialogs, popovers, menus, date picker, keycaps).
- Structural tests (`npm test`), run against every variant; they also fail when `themes/` or `package.json` is out of date with `src/`.
- Live validation on app.logseq.com 2.0.1 (light, dark, accents logseq/tomato/blue/none) fixed three rules:
  - Callout icons: the IMPORTANT, WARNING and CAUTION icons carry a `fill="var(--color-…)"` attribute, so the rule now also sets `fill: currentColor`.
  - Shortcut keycaps: core's `.shui-shortcut-combo.shui-shortcut-glow` and `kbd.shui-shortcut-key` out-ranked the keycap rules; the selectors are now more specific.
  - Date picker: every day is round, so the keyboard focus ring and the selected fill are circles.
- Menu and select highlights: hovered/chosen rows in filters, autocomplete, dropdown, context and select menus and the command palette use a new `--ink-hover` token, a near-neutral cool grey (light `#dcdee1`, dark `#404244`). In dark mode the old highlight was darker than the popover (contrast 1.04) and nearly invisible (reported from the Theme-Lab pass on the tag-table filter). A test now requires ≥ 1.3:1 against `--ink-float` in both modes. The filter list itself was also losing to core rules: `#ui__ac-inner .menu-link.chosen` (an ID selector) painted the chosen row with the popover colour, and `.cp__select-main .menu-link.chosen` dimmed its text. The theme now matches those selectors.
- Menus with a non-default accent colour: hovered items in the plugins toolbar menu, the header "…" menu and the themes dialog were painted with a grey equal to the popover in dark mode; they now use `--ink-hover`.
- Theme-Lab human test graph (`npm run lab [-- --variant <id>]`, `npm run lab:feedback`).
